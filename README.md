# LifePilot AI

LifePilot AI is an action-oriented conversational assistant designed to turn natural-language requests into organized tasks, schedules, reminders, and personalized workflows.

## Project Status

🚧 Currently under development for the Build, Ship, Shape: Amazon Developer Hackathon.

## Planned Features

- Natural-language conversational interface
- Intelligent task understanding
- Automatic task breakdown
- Schedule and reminder planning
- Context-aware interactions
- Personalized daily plans
- Visual action and schedule dashboard

## Technology

- React
- JavaScript
- Node.js
- Amazon Bedrock
- Alexa+ simulated web experience
